# Photos folder

Drop your stock photos here (JPG, JPEG, PNG, WEBP).

The bot will automatically pick up all photos in this folder and post them daily at 8:00 AM MYT.

**Tips:**
- Bot supports up to ~30 photos (will auto-split into albums of 10)
- Use clear filenames (e.g., `01-y15zr.jpg`, `02-r15m.jpg`) so they post in order
- Replace photos here whenever stock changes
